# Truck Simulator Tool App

The Truck Simulator Tool App is an Android application that can be used as an extension to the [Truck Simulator Tool](https://github.com/Sebastian7870/Truck-Simulator-Tool).

The App deserializes a .json file of server data recieved from the Truck Simulator Tool and displays it on your mobile phone.

## Installation and Usage

1. Download and install the [latest release](https://github.com/Sebastian7870/Truck-Simulator-Tool-App/releases/tag/v1.0.0)
2. Find the IP address in the Truck Simulator Tool ("Server" → "ip adress")
3. Start the application and enter the IP adrress

> **Note**
> 
> As the Truck Simulator Tool App only receives the data processed by the Truck Simulator Tool, the WPF application must stay open while using the app.

<br>

## Requirements
* OS: Android 8.0 or newer
* Truck Simulator Tool is required
